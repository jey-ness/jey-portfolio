# jey-portfolio

Personal portfolio site for Jey Tsymbaluk.

## Structure

- `index.html`: page markup and portfolio content
- `styles.css`: visual design, layout, and responsive styles
- `script.js`: tabs, case study routing, contact flow, lightbox, and image zoom controls

## Notes

- This is a lightweight static site intended for GitHub Pages.
- Portfolio images are hosted remotely.
- The site uses hash-based routing for tabs and project detail views.
